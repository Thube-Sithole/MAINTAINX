# MAINTAINX

Predictive Industrial Equipment Intelligence

## Overview

MAINTAINX is a predictive maintenance intelligence platform
designed initially for mining cone crushers.

The initial use case focuses on detecting developing bearing
degradation through simulated industrial telemetry.

## Architecture

- Business Central: Enterprise application and workflows
- AL: Business Central extension
- Python: Predictive intelligence engine
- FastAPI: REST API
- PostgreSQL: Analytical data storage
- scikit-learn: Machine learning

## Initial Development Scope

1. Cone crusher simulation
2. Bearing condition monitoring
3. Anomaly detection
4. Predictive health assessments
5. Business Central integration
